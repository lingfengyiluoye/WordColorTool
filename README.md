# WordColorTool

常驻屏幕的 Word 取色 / 格式小工具。**没有热键**，就是一个小面板：

- 在 Word 里选中要改的文字（或把光标放到要输入的位置）
- 在面板上选颜色、字号、字体
- 点「**确定**」→ 应用到 Word 当前光标处，并**锁定**
- 之后接着打出来的字一直是这套格式，**不会继承上一个字的格式**
- 想换 → 改面板 → 再点「确定」；「清除格式」一键恢复 Word 默认

## 面板长什么样

```
┌─ WordColorTool ────── 左键按住标题栏可拖动 ─┐
│ ① 颜色（选中后点下方「确定」）        [当前色] │
│  ■ ■ ■ ■ ■ ■ ■ ■      ← 24 个色块             │
│  ■ ■ ■ ■ ■ ■ ■ ■                            │
│  ■ ■ ■ ■ ■ ■ ■ ■                            │
│ ② 字号 / 字体                                │
│  字号[默认▾]  字体[        ]                  │
│  [确定]  [清除格式]  [自动颜色]               │
│ ③ 预设（点一下载入，再点「确定」）             │
│  [预设名        ] [存为预设] [删除]            │
│  ┌──────────────────────────────┐            │
│  │ 预设列表                      │            │
│  └──────────────────────────────┘            │
│  当前：未锁定                        [隐藏]   │
└──────────────────────────────────────────────┘
```

窗口置顶、不占任务栏按钮。**点面板不会抢走 Word 的焦点**（Word 里正常打字选字不受影响），
只有点输入框打字、或用取色器时，Word 才临时让出焦点，用完自动恢复。

- **拖动**：只有左键按住顶部标题栏才能拖动；拖出屏幕会自动拉回可见区域
- **位置**：默认屏幕正中；也可以在托盘左键图标显示/隐藏

## 颜色板

24 个常用色，前 4 个是批改用的**鲜艳红**（`E60000` / `FF0000` / `FF2A2A` / `C00000`），
其余是橙黄绿蓝紫粉青灰黑。鼠标悬停显示色名 + 色值，每个色块位置固定、不会被挡住。

想加颜色：编辑 `MainForm.cs` 顶部的 `ColorConfig` 数组，整行加 `new ColorBinding("RRGGBB", "色名"),`。
色板按 8 列网格排列，增删不影响其他色块点得到。

## 预设怎么用

1. 选好颜色 / 字号 / 字体
2. 在「预设名」框输入名字（如"批改红"）
3. 点「存为预设」
4. 以后在列表里**点一下**该预设 → 面板自动载入设置 → 再点「确定」

预设存在 `%APPDATA%\WordColorTool\presets.txt`（纯文本，每行一条），**重启后还在**。
选中列表项点「删除」可移除。

## 「确定」「清除格式」「自动颜色」

- **确定**：把面板当前设置写到 Word 选区，并启动锁定（300ms 定时器持续维持）
- **清除格式**：把 Word 选区恢复默认（自动色 / Normal 样式字号 / 清空字体名），并解除锁定
- **自动颜色**：颜色跟随 Word 默认（主题黑）

## 关于 Word 连接不上 / 操作失败

工具用 `Marshal.GetActiveObject("Word.Application")` 从系统 ROT 连接 Word。已知有两种情况：

**1. Word 后台残留实例（最常见）**
Word 先前的实例没退干净时，新开的文档会另起一个进程，但 ROT 仍指向那个**没有窗口、没有文档**的残留实例。
工具连上它之后，读不到你的文档、也写不进去。

程序会自动检测（连到的实例 `Documents.Count == 0`），然后弹窗告诉你：

- 哪个才是你正在用的 Word 窗口（列出文档标题）
- 检测到几个无窗口的残留进程
- 问你是否结束它们

选「是」：它**只结束无窗口的 WINWORD 进程**（绝不碰你有文档的窗口），等最多约 2 秒重新连接，连上后直接把颜色/字号应用上，不用你再点一遍。

**2. 文档受保护 / 只读**
从网上下载的 Word 文件默认处于「受保护的视图」，这时写不进去。Word 顶部会有黄条提示，
点「启用编辑」后再试即可。工具的报错信息里也写了这条。

## 颜色是怎么算的

Word 的字体颜色用 OLE 的 BGR 约定：

```
值 = R + (G << 8) + (B << 16)
```

所以面板里写的 `RRGGBB` 要重排。例如 `E60000`（鲜红）→ `0x0000E6` = 230。
程序优先写 `Font.ColorRGB`，遇到不暴露该属性的 Word 自动退回 `Font.Color`（两者接受同样的值）。

## 已知限制

- **加粗 / 斜体 / 下划线 / 删除线做不了**：实测本机（64 位 Office 365 被 32 位程序自动化时）
  Word 对布尔型格式属性的赋值不落地——所有 API 路径试过都一样，而颜色/字号/字体都正常。
  所以面板只做颜色、字号、字体三项。
- **位数**：exe 按 `/platform:x86` 编译。实测 32 位程序可以连上 64 位 Word（颜色字号可用）。
- **强拉回**：锁定生效期间手动改颜色/字号会被定时器改回锁定值（这是需求本身）。
  要临时用别的格式，先点「清除格式」，或把光标移到设色点之前（自动解除锁定）。
- 不做开机自启、不写注册表、不改 Word 设置；退出时注销定时器并释放托盘图标。

## 怎么重新编译

退出正在运行的程序，然后**双击 `build.cmd`**：

```
C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe /nologo /target:winexe /optimize+ /platform:x86 /out:WordColorTool.exe /r:System.dll /r:System.Windows.Forms.dll /r:System.Drawing.dll /r:Microsoft.CSharp.dll Program.cs MainForm.cs
```

- 只编 `Program.cs` + `MainForm.cs` 两个文件，产出单个 exe
- `/r:Microsoft.CSharp.dll` 是给 `dynamic` 后期绑定用的
- `/platform:x86`：匹配 32 位 Word

## 关于源码里的 C# 5 约束

编译用的 csc 是 .NET Framework 自带的 4.8.9232.0，**语言级别最高 C# 5**，
所以代码里不能用元组、字符串插值、nameof、out 变量、表达式体成员等 C# 6+ 语法。
